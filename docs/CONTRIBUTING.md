# Contributing

Useful contributions include reproducible build reports, device-variant testing, module documentation and isolated feature tests.

Include:

- exact device model and ROM build;
- kernel image and config SHA-256 values;
- the command or module that triggered the issue;
- boot mode, slot and recovery behavior;
- sanitized logs.

Do not submit private boot images, Magisk databases, keys, Wi-Fi credentials or full device dumps. Changes affecting boot layout, initramfs handling or module loading require a documented rollback test.
